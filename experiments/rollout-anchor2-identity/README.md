# 新意锚② 的可换算性复核与 P-6 重建形式（2026-11-03 M1 第三十一／三十二批）

CPU 只读复算，不跑 GPU、不改任何既有读数。核对材料：第三十一批 [check_identity.py](check_identity.py)（`--verify` exit 0）、[negative_control.py](negative_control.py)（exit 0）、[summary.json](summary.json)；第三十二批 [check_reconstruct_form.py](check_reconstruct_form.py)（`--verify` exit 0）、[negative_control_form.py](negative_control_form.py)（4/4 注入抓到，exit 0）、[p6-form.json](p6-form.json)；[run-info.json](run-info.json)。正文落笔：[主文档 §20.3.6／§20.3.7](../../notebook/rollout-performance-research.md)、[§11.6](../../notebook/rollout-performance-research.md)。

## 为什么要做

§20.3.5 把"同栈实测的 `G_k`"当作锚②（阶段占比中介定律）可换算的证据。本轮复核这句话时发现两件事：① 该处引用的五对 `G_k` 实际全来自 re-anchor 2+2 一套放置（早前批次的转述里出现过两套放置混用），② 更根本的是——**没有人把 `s_k` 与 `G_k` 一起代回公式、与实测整步比对照过**。本批只做这一件事。

## 结果

### A. 引用面：五对 `G_k` 都来自同一套放置

两套放置（`g1p/g2p/g4p` 的 1+1／2+2 与旧 `g1/g2/g4` 的 2+0／3+1）的分阶段 `G_k` 差别很大（`update_actor` 2 卡 1.628 vs 1.211、`ref` 4 卡 3.147 vs 2.623），引错一套会让"加卡收益被更新侧吃掉"的量级差 30% 以上。实测核对：§20.3.5 引用的五对逐项落在 re-anchor 2+2 轨内，**引用面本身无错配**；风险在转述环节（见 §20.3.6 的三条改法）。

### B. 公式 vs 实测整步比

取 §13.25／§20.3.1 写下的形式 `整步× = 1/(Σ_k s_k/G_k)`，`s_k = t_k^目标/Σt^目标`、`G_k = t_k^基线/t_k^目标`：

| 臂（同一份归档，放置内部一致） | 公式 | 实测整步比 | 差 |
|---|---|---|---|
| g1p → g2p（1+1） | 1.4485 | 1.5264 | **−5.1%** |
| g1p → g4p（2+2） | 1.6429 | 1.9419 | **−15.4%** |

同一类核对换成单轴干预（poll 2.0→0.1，`G_k` 名义全 1）时公式给 1.0235／1.0148，实测 1.0373／1.0202，差 −1.33%／−0.53%——**在小效应上公式凑得上，在大效应上系统性偏低**。

两条结构性发现：

1. **公式在"没有加速"时给 1，不是给基线/目标的整步比。** 令全部 `G_k≡1`，公式值恰为 `Σs_k = 1`；而真实整步比应为 `T1/TN`。这说明这个式子度量的是"相对自身的归一化加速"，**不是**"两配置之间的整步秒数比"，除非额外乘上 `T1/TN` 或声明它只在单配置内部做敏感性分析。负向对照（`negative_control.py` 第 3 组）钉住了这一点。
2. **把各阶段省下的秒数逐项相加的形状（`(T1/TN)·Σ s_k²·G_k`）同样不成立**：2 卡给 0.6761、4 卡给 1.0729，与实测 1.5264／1.9419 差得更远。原因是这种形式要求"份额在基线与目标两侧相同"，而分档之后份额本身在变（`update_actor` 占分项和的比例 1 卡 0.484 → 4 卡 0.450），把份额同时放进乘子与权重就会把同一份结构变化算两遍（口径依赖见 §20.3.1 的分母条件：份额取哪一侧的分母未声明时，两种取法差 0.2–0.5%，属口径量；本条说的差异远大于此，是形式本身的量纲问题）。

### C. 真正闭合的账

同一批归档上成立的是**逐阶段秒数相加 + 计时缺口**：`Σ_k t_k^基线/G_k` 与分项和口径下实测的分项和逐位相同，分项和与整步的缺口恒定在 **0.23–0.31%**（g2p 0.27%、g4p 0.28%，poll 六臂 0.23–0.31%）。这与 §13.46 用另一批归档标出的 0.28% 是同一个量。

## 边界

- **单栈单点**：verl `24f25b03`＋Qwen2.5-1.5B＋gsm8k 短答案、4090-1；单 seed、每臂单次或两跑。结论是"这几个式子在这批归档上重建不出整步比"，不是"这类形式化在任何系统上都不成立"。
- **不作废任何既有读数**：§13.25／§13.45／§13.46 的阶段时间、`G_k`、缺口标定全部不变；本批只否定了"`s_k` 与 `G_k` 的某种组合能重建整步比"这一读法。
- 未复核 `Σ_m a_m/T`（新增阶段）这一项：本批所有臂都没有新增阶段，它在这批数据上恒为 0，加进去也不可能补上 5–15% 的差额。

## 第三十二批（§20.3.7）：P-6 重建形式

上一批只做了否定——`s_k`／`G_k` 代回 §13.25 的乘积式重建不出整步比——并把"给出一个能重建的形式"登记为必补项 P-6。本批补完。形式：

```
整步比 T^基线/T^目标 = [ 1/(Σ_k s_k^基线/G_k) ] × (δ^基线/δ^目标)
    s_k^基线 = t_k^基线/S^基线，S = Σ_k t_k，G_k = t_k^基线/t_k^目标，δ = S/T
```

| 臂 | 实测整步比 | 旧式（目标侧份额） | 新式第一项（基线侧份额） | 完整新式 |
|---|---|---|---|---|
| g1p→g2p（1+1） | 1.5264 | −5.10% | −0.01% | **−0.007%** |
| g1p→g4p（2+2） | 1.9419 | −15.40% | +0.01% | **+0.010%** |
| poll 2.0→0.1（2 卡） | 1.0373 | −1.33% | +0.01% | +0.019% |
| poll 2.0→0.1（4 卡） | 1.0202 | −0.53% | −0.02% | −0.039% |
| poll 2.0→0.5（4 卡 DAPO） | 1.0451 | −0.64% | −0.01% | −0.019% |
| poll 2.0→0.1（4 卡 DAPO） | 1.0416 | −0.41% | −0.01% | −0.019% |
| poll 2.0→0.1（2 卡 DAPO inflight=1） | 1.0312 | −0.26% | +0.01% | +0.019% |
| pbase→p4base（跨放置，只作对照） | 1.5325 | −3.96% | +0.08% | +0.163% |

**它是恒等不是拟合**：`Σ_k s_k^基线·(T^基线/t_k^基线) = T^基线/S^基线 = 1/δ^基线`，代入化简即得，无自由参数。

**旧式为什么错**：同一算子把份额取在目标侧，则 `Σ_k s_k^目标·(T^目标/t_k^目标) = 1/δ^目标`，式子退化为 `δ^目标·(S^目标/S^基线)`——连加速倍数都不是。根因是**份额取了加速之后的那一侧**，把要度量的效应预先算进了权重，效应越大算得越少。

**两个限定（必须随结论写）**：① 本栈两侧缺口几乎相同（|差| ≤0.08%），第一项单独就接近整步比——这是数据事实不是恒等；负向对照把两侧缺口拉开 20%，第一项偏 20%，乘上缺口之比才回到 0。② 单栈单点，只有两个加卡臂同时含大小效应，显著程度不外推。

**负向对照（`negative_control_form.py`，4/4 抓到）**：份额换回目标侧 → 误差 −15.4%；谎报 `update_actor` 无加速 → −54.9%；缺口拉开 20% → 第一项偏 20%、完整式偏 0、方向写反偏 −36%；本栈缺口方向写反只差 0.006%（记录"缺口因子≈1"的含义，不是检验项）。
