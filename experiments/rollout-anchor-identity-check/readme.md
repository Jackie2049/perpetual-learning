# rollout-anchor-identity-check — 会计面判据的同栈复核

**一句话**：把 §11.4 给会计面（耦合面 2：阶段占比与跨阶段残差）的定量可证伪点，在 M5 已有的同栈三档数据上跑一遍，看它站不站得住。

**结论先行**：判据站得住，但**必须补一条前提**——恒等式里的份额 `s_k` 要以「各阶段墙钟之和 Σt_k」为分母，不能以整步 `T` 为分母。分项和口径下，恒等式与"逐阶段时间相加"逐位相同（差为机器零）；整步口径会造出 0.22%（2 卡）／0.51%（4 卡）的伪偏移。

## 输入

只读两份既有归档，**不重算任何原始计时**：

| 文件 | 用途 |
|---|---|
| `experiments/rollout-g8-candidate-g/reanchor-summary.json` | §13.45 的 G1／G2p／G4p 逐阶段均值与 `stage_scaling` |
| `experiments/rollout-g8-candidate-g/ab-summary.json` | §13.42 的 A/B 放置八档（pA1–pA4／pB1–pB4） |

sha256 见 [run-info.json](run-info.json)。

## 判据与做法

会计面主张"报值超纯阶段投影的差额只能来自跨阶段残差"。可证伪形式取 §20.3.1 锚② 的恒等式：

```
整步× = 1 / ( 1 − Σ_k s_k(1 − 1/G_k) + Σ_m a_m/T )
```

脚本对每档做三件事：

1. **恒等式 vs 逐阶段相加**：`1/(1−Σs_k(1−1/G_k))` 与 `Σt_k^base/G_k` 的倒数是否同值。分项和口径必须恒等，整步口径必须**确实不同**（否则"基线口径"这条提醒就是空话，脚本把这点也做成断言）。
2. **残差分层**：把"实验值相对投影"的差拆成半程（投影 vs 同一份分项）与全程（分项和 vs 整步）两段。
3. **放置对照**：A/B 八档各自的"分项和 − 整步"缺口是否稳定。

## 读数

| 档 | 实测整步 | 投影 | 实测× | 投影× | 分项和口径差 | 整步口径偏移 |
|---|---|---|---|---|---|---|
| g2p（1+1） | 18.031s | 17.954s | 1.5264 | 1.5329 | **0.00e+00** | −0.22% |
| g4p（2+2） | 14.173s | 14.133s | 1.9419 | 1.9474 | **0.00e+00** | −0.51% |

- 本栈 `Σt_k` 比整步小 **0.28%**（G1：27.4459 vs 27.5221s），这就是 §20.3.1 锚② 记的"0.040–0.076s 残差"。
- 实验值相对投影的差是**正的**（+0.077s／+0.040s），等于 `−半程−全程`；半程（−0.027／−0.0001s）与全程（−0.050／−0.040s）**同号叠加**，所以它**不含任何 G_k 之外的额外重叠收益**。
- A/B 八档缺口 **−0.041±0.001s**，两档整步相差 16.3% 时缺口不变 ⇒ 这是同一份插桩的固定缺项（0.20–0.26%），可当本栈的计时缺口标定值。

## 验证范围与边界

- **单栈单点**：1.5B／gsm8k 短答案／单 seed；三档各单次运行。结论是"这份账在这套插桩上的口径性质"，**不是**"跨阶段重叠收益不存在"。
- **只测会计不测机制**：判据成立只说明同一份测量两边相等（§21.9 同一告诫），不能据此推出任何阶段加速的归因正确。
- **`adv` 在恒等式中取 `G≡1`**（构造选择，量级 0.11–0.14s）；`stage_scaling` 里 adv 的 0.806／1.000 是实测比值，两者不是同一个量。
- `--verify` 四条断言：分项和口径恒等／整步口径确实偏移／全程误差量级 ≤0.5s／实测加速与 §13.45 一致（1.5264／1.9419）。
